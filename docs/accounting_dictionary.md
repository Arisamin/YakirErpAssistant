# Israeli Accounting Dictionary & Guide for Software Engineers

Welcome to the bridge between **Software Architecture** and **Israeli Bookkeeping (הנהלת חשבונות)**.
This guide is designed for developers with zero accounting background. Think of accounting as an immutable, transactional distributed ledger with strict balancing constraints and regulatory schema requirements.

---

## 1. Foundational Accounting Architecture

| Hebrew Term | Phonetic | English Equivalent | Software / Logical Analogy |
|---|---|---|---|
| **הנהלת חשבונות כפולה** | *Hanhalat Heshbonot Kfula* | **Double-Entry Bookkeeping** | **Balanced Transaction Invariant:** Every atomic transaction must have equal debits and credits ($\sum \text{Debits} = \sum \text{Credits}$). Money never appears or disappears; it moves between state nodes. |
| **פקודת יומן** | *Pekudat Yoman* | **Journal Entry** | **Atomic DB Transaction Record:** An immutable record containing 2 or more line items (rows) that transfer value between accounts with an exact net balance of zero. |
| **כרטיס חשבון / מפתח חשבון** | *Kartis Heshbon / Mafte'ach Heshbon* | **General Ledger Account / Account Key** | **Entity ID / Wallet Address:** A unique identifier (e.g., `30001` for Supplier X, `40000` for Office Expenses) holding a running balance. |
| **חובה** | *Hova* | **Debit (Dr)** | **Left-side ledger entry:** Increases an Asset (money in bank, equipment) or Expense (money spent). Decreases a Liability (debt owed) or Equity. |
| **זכות** | *Zkhut* | **Credit (Cr)** | **Right-side ledger entry:** Increases a Liability (money owed to supplier) or Income (revenue). Decreases an Asset. |
| **מאזן בוחן** | *Ma'azan Bohan* | **Trial Balance** | **System Integrity Check / Checksum:** A query summing all debit balances and credit balances across all accounts to verify that the entire database is in balance. |
| **תאריך אסמכתא** | *Ta'arikh Asmakhta* | **Document / Reference Date** | **Created Timestamp:** The date printed on the original paper/PDF invoice by the issuer. |
| **תאריך ערך** | *Ta'arikh Erekh* | **Value Date / Due Date** | **Execution Timestamp:** The date on which funds actually leave or enter the bank account, or the payment due date. |
| **אסמכתא** | *Asmakhta* | **Reference / Document Number** | **External ID:** The official invoice number generated by the external vendor (used for deduplication). |

## 2. Israeli Business Document Types (סוגי מסמכים)

| Hebrew Term | Meaning & Purpose | Regulatory / Software Implication |
|---|---|---|
| **חשבונית מס** (*Heshbonit Mas*) | **Tax Invoice:** Demands payment for goods/services delivered. | The core document for B2B. It legally obligates the seller to pay VAT to the government, and allows the buyer to claim a VAT refund (*מע"מ תשומות*). |
| **חשבונית מס קבלה** (*Heshbonit Mas Kabala*) | **Tax Invoice / Receipt:** Invoicing and payment combined in one step. | Created when a customer pays immediately upon purchase (cash, debit, or credit card). Triggers both invoice accounting and payment ledger records at once. |
| **קבלה** (*Kabala*) | **Receipt:** Proof of fund transfer only. | Contains details of payment instruments (cash, check number, credit card transaction). Does not generate VAT liability on its own. |
| **חשבונית זיכוי** (*Heshbonit Zikuy*) | **Credit Note / Refund Invoice:** Reverses or reduces an invoice. | Negative invoice. Inverts debit and credit flows, reducing both the supplier debt and reclaimed VAT. |
| **חשבונית עסקה** (*Heshbonit Iska*) | **Transaction / Proforma Invoice:** Request for payment before tax liability. | Used by service providers who pay VAT only upon actual cash collection (*בסיס מזומן*). Cannot be deducted for VAT until transformed into a Tax Invoice. |
| **תעודת משלוח** (*Te'udat Mishlo'ach*) | **Delivery Note / Bill of Lading:** Confirms physical delivery of inventory. | Updates stock/warehouse quantities in the ERP before the final financial invoice is billed. |
| **הזמנת רכש** (*Hazmanat Rekhesh*) | **Purchase Order (PO):** Approval request to buy goods/services. | Internal approval document used for 3-way matching: PO vs. Delivery Note vs. Supplier Invoice. |

## 3. Israeli Taxation & Regulatory Mechanics

| Hebrew Term | Meaning | Software / Integration Rules |
|---|---|---|
| **מע"מ (מס ערך מוסף)** | **Value Added Tax (VAT)** | Consumption tax added to products/services (standard rate 17% or 18%). |
| **מע"מ תשומות** (*Ma'am Tsumot*) | **Input VAT (Expenses):** VAT paid to suppliers. | Reclaimable tax asset. The business pays VAT to vendors and receives a refund or credit from the government. |
| **מע"מ עסקאות** (*Ma'am Iskaot*) | **Output VAT (Sales):** VAT collected from customers. | Tax liability owed by the business to the government. |
| **מספר הקצאה** (*Mispar Haktza'a*) | **Invoice Allocation Number (Israel Invoicing Law):** Real-time clearance ID. | Israeli Tax Authority API mandate: Invoices above statutory limits (starting 25,000 NIS in 2024, descending down to 5,000 NIS) require a real-time allocation number via government REST API to allow VAT deduction. |
| **ניכוי מס במקור** (*Nikuy Mas BeMakor*) | **Withholding Tax:** Tax deducted at the source of payment. | When paying a supplier, if the supplier does not have a 0% exemption certificate, the buyer must withhold a legally specified percentage (e.g., 5%, 20%) and transfer it directly to the Tax Authority instead of the supplier. |
| **אישור ניהול ספרים** (*Ishur Nihul Sfarim*) | **Bookkeeping Compliance Certificate:** Proof that vendor keeps valid books. | Validated via Israel Tax Authority public web services to verify legitimate business status. |
| **עוסק מורשה (ע.מ.) / חברה בע"מ (ח.פ.)** | **Authorized Dealer / Ltd. Company ID** | 9-digit official tax identification number validated via modulo-10 / Luhn algorithm checksum. |

## 4. Hashavshevet (חשבשבת) Specific Terms & Concepts

| Hashavshevet Term | Technical Description | Integration Usage |
|---|---|---|
| **מנה (Batch)** | A container grouping multiple unposted journal entries for batch processing and audit review before committing them to the permanent ledger. | Unapproved imports go into an open batch (*מנה פתוחה*), allowing bookkeepers to review and edit before final posting (*קליטת פקודות יומן*). |
| **כרטיס חו"ז (חשבון וזכות / לקוח-ספק)** | Mutual receivable/payable account tracking what a supplier is owed or what a customer owes. | Primary account keyed by supplier ID (ח.פ. or custom code). |
| **חשבון הוצאה (Expense Account)** | The category account classifying what the expense was for (e.g., Software Subscriptions, Office Supplies, Logistics). | AI / Rule engine predicts and assigns this key based on invoice line items or supplier defaults. |
| **H-Connect** | Modern REST API middleware for Hashavshevet ERP. | Allows cloud web apps to query accounts and inject journal entries via JSON endpoints (`movein`). |
| **Movein (MOVIN.DOC / MOVIN.PRM)** | Standard text file specification used for decades by Hashavshevet to batch-import transactions. | Failsafe import fallback when H-Connect is not installed or when running on legacy air-gapped on-premise servers. |

## 5. Global vs. Israeli Accounting Systems: The Intuit / QuickBooks Case

| Topic / System | Explanation for Software Engineers | Israeli Accounting Context |
|---|---|---|
| **Intuit QuickBooks** | Global benchmark for SMB cloud accounting (dominant in US/UK/Canada). | **Not certified in Israel:** Under Israeli Bookkeeping Directives (*הוראות ניהול ספרים*), an accounting software must be registered with the Israel Tax Authority. QuickBooks does not produce mandatory Israeli reports (PCN874 VAT reports, Form 856 for withholding tax, Uniform Audit File - BKMVDATA), nor does it integrate with the Israeli Invoice Allocation API (*מספר הקצאה*). |
| **מערכת ממוחשבת מוכרת** (*Certified Accounting Software*) | A software system formally registered and audited to comply with the Israel Tax Authority rules. | Prevents tampering with sequential document numbers, invoice dates, or audit trails. Systems like Hashavshevet, Priority, and Rivhit are certified. |
| **גשר הנהלת חשבונות** (*Bookkeeping Bridge / Shadow Ledger*) | An ETL/integration middleware syncing an uncertified system to an Israeli certified system. | Israeli subsidiaries of US firms that manage global books in QuickBooks must use an ETL bridge or CPA agency to sync data into an Israeli certified engine like Hashavshevet for statutory tax filings. |
